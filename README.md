# Portfolio - Pauline Theodore

Bienvenue sur mon portfolio de testeuse logiciel QA.

Ce projet a été réalisé dans le cadre de ma formation afin de présenter mes compétences, mes projets et ma démarche professionnelle.

---

## Objectifs du projet

Ce portfolio répond à deux objectifs principaux :

- Présenter mon profil, mes compétences et mon parcours
- Mettre en avant mes projets à travers une interface moderne et performante

---

## Technologies utilisées

- HTML5
- CSS3 (Flexbox, animations, responsive design)
- JavaScript (manipulation du DOM, fetch API)
- Bootstrap 5
- JSON (données dynamiques)

---

## Compétences mises en œuvre

- Conception de stratégies de test
- Rédaction de cahiers de recette
- Tests fonctionnels et exploratoires
- Automatisation de tests (Cypress)
- Gestion des anomalies (Jira)

### Développement
- Manipulation du DOM en JavaScript
- Intégration responsive
- Communication avec API
- Structuration de données JSON
